用 ChatGPT 專案練口試

已經有 ChatGPT（免費版或 Plus 都可以）、不想另外申請 API key 的話，照下面五步設定一次，之後在 ChatGPT 裡就有一位依你的審查資料出題、批改、追問的口試委員。想要倒數計時、錯題本勾選這些介面，請改用網頁版。

  1. 下載規則檔

    這個檔案寫著委員怎麼出題、批改、追問，等一下要上傳到專案裡。

    下載「口試委員規則.md」

  2. 在 ChatGPT 建一個專案

    手機 App：點左上角選單，找到「專案」，新增一個專案，名稱可以叫「口試練習」。電腦版：左側欄的「新專案」。按鈕名稱可能因版本略有不同。

  3. 貼上專案指令

    打開專案的設定，找到「指令」欄位，貼上下面這段，再把【我的面試資訊】填好。

    你是我的碩士班甄試口試委員兼教練。請依照專案檔案「口試委員規則」運作：出題、抽題、批改、追問、錯題本的做法都在裡面，一律用繁體中文。

【我的面試資訊】
學校系所與面試日期：（例：某某大學資訊管理研究所，11/20；多間學校就一行一間）
口試形式與重點：（可貼簡章上的口試說明，沒有就留空）
補充背景檔案：（委員看不到、只用來核對事實的檔名，沒有就寫「無」；其他檔案都當作審查資料）
口徑提醒：（不能講或要注意的說法，一行一條，沒有就寫「無」）

  4. 上傳檔案到專案

    在專案裡新增檔案：口試委員規則.md，加上你交給學校的審查資料（自傳、讀書計畫、作品集，PDF 或 Word 都可以）。有補充背景（例如專案完整紀錄）也可以一起放，記得在指令裡寫上它的檔名。

    免費版每個專案最多放 5 個檔案，Plus 最多 25 個。檔案太多時，可以把幾份文件合併成一個 PDF。掃描檔讀不到字，請用可以選取文字的檔案。

  5. 在專案裡開新對話

    說「出題」，委員會先依你的資料整理題庫；之後說「抽一題」開始練。回答時用鍵盤上的麥克風說出來就好。

    出題依審查資料逐段出題，附事實卡與出處
    抽一題／下一題委員只問題目，等你回答
    看提示講不出來時，看這一題的事實卡
    第 N 題、只練〇〇指定題號或主題
    （直接回答）批改：講錯、漏掉的重點、口徑、建議、口頭禪，可能再追問
    錯題本整理這個對話裡還沒改好的地方
    換學校〇〇改用另一間學校的委員身分

小提醒

  • 同一次練習盡量在同一個對話裡進行，「錯題本」才整理得到前面的題目。
  • 委員只給改進方向，不會給範本答案；追問要不要回答由你決定，同一題最多追問 2 次。
  • AI 可能記錯資料，事實卡上的出處可以回原檔核對。
  • 你的資料會上傳到 ChatGPT，依你帳號的資料設定處理。
